Cloudflare Worker + D1 management system for 50 members.

### Features
- Public dashboard, members, monthly collection, fund and reports
- Admin-only member/payment/fund editing
- Server-side session authentication
- D1 database binding
- Mobile-friendly Bengali UI

- Shares: 5 / 6 / 10
